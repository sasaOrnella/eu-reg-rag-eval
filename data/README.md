**Download date:** 2026-11-03

The corpus uses the official English HTML texts from EUR-Lex:

| Regulation | Local source | Official URL | Extracted units |
|---|---|---|---|

| EU AI Act — Regulation (EU) 2024/1689 | `data/raw/ai_act.html` | https://eur-lex.europa.eu/legal-content/EN/TXT/HTML/?uri=OJ:L_202401689 | 113 articles + 180 recitals |

## Extraction and cleaning

The `extract_text.py` script parses the downloaded HTML and extracts **structured article and recital units** into JSONL. It retains the substantive text of articles and recitals, removes footnotes, and does **not** include annexes. The processed corpus is not yet split into retrieval chunks; chunking is performed later in the evaluation pipeline.

Run from the repository root:

```bash
python extract_text.py
```

**`data/processed/` is generated by `python extract_text.py`.** Expected outputs include `gdpr.jsonl` and `ai_act.jsonl`.

The counts above describe the extracted units, not the number of retrieval chunks. If the source HTML or extraction logic changes, regenerate the processed files and verify the counts.
