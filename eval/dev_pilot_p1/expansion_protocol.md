# 扩样与确认性评测协议

修订日期 **2026-11-20**。以下分层、检验族、汇总方式和参数均为 Dev Pilot 后的前瞻性修订。项目 README 保留原始预注册假设。本轮统计只用 Dev 试算，扩样与确认性评测尚未启动。

## 盲生成与审核

1. 冻结法规语料、题型说明、配额、抽样种子和证据单元池。编题者只收到指定法规原文与标注规则。协调者负责旧题去重和正证据单元的跨 split 隔离。编题与审核均隔离既有题面、检索分数、排名及错例。
2. 据原文写题、答案和最小证据，记录来源单元、约束、例外及可接受的替代证据。多跳每段须提供必要信息。弃答题查两部限定文本内的相关概念，登记所缺的事实。AI 起草元数据按题记录提供方、模型版本或可得的快照 ID、完整提示词或有版本及哈希的提示词引用、生成随机种子、生成日期（含时区）和生成参数。接口没有种子时如实登记未提供。
3. 使用盲审判断语义、证据、重复、泄漏和符合预设配额的情况。计划由独立人工审阅者审查确认性题目，随机抽约20%双审，记录分歧及裁决。起草来源与审核状态分别登记，缺少签认时保持 pending human review。
4. 协调者在评分前按冻结版 lexical_overlap 从题面和金引文计算未舍入分数，完成分层与抽样。候选及落选理由留档。冻结题库与语料哈希、主评估配置、模型版本和脚本版本。当前 Test 继续锁定。获准启动确认性评测后按一次冻结流程运行。

每个新增单元的26道可回答题执行以下交叉配额。证据和词汇配额分别验算，避免集中于某一题型。

- **High/Low**。分数 ≥0.30 为 High，<0.30 为 Low。每个新增单元 High 至少11/30，合并单元至少18/50，均按总题数保守计算，因而在有金证据的题中也满足35%。若旧单元有 H 道 High，从新增可回答题中至少纳入 max(11, 18−H) 道 High，其余为 Low，保留 Low 样本。4道弃答题的重合度为不适用。原锁定题只使用冻结标注计算配额，结果文件保持锁定。
- **证据类型**。以题为单位，目标19道仅 Articles、5道仅 Recitals、2道为 Articles + Recitals，外加4道无金证据的弃答题。序言须对回答提供必要信息，两个法规分别覆盖预先列出的主题和章节。每单元至多1道数量缺失题，全库预计至多9/29道。
- 约200题是资源目标。若证据充分性、独立证据单元或交叉配额不足，记录实际偏差，先盲补候选。评分前只用 Dev 配对差值做精度和功效模拟。

原40道锁定题与新增60道独立锁定题共同组成确认性评测集。主结果按题等权汇总，另列旧/新队列各自样本量、有效簇数、效应和区间。保留两组题的身份和原 split。题型、旧/新队列单独的比较用于描述。

## 确认性配置与检验族

预算固定 **8000 字符**。Chunk Size 固定为400、800、1200、2000字符。H2 四档按题等权平均，H1 用同一题的四档构造形状对比。Hybrid 固定 **pool=50、rrf_k=60**，融合结果取前50再按严格预算入选。主指标为任意字符重叠的 Evidence Recall。50%跨度覆盖、4000预算、单尺寸方法对比、替代重合阈值和题型对比列为探索性。

主要族共 **8 个声明**，对其 p 值一起做 Holm，族错误率 0.05。配对效应均为前者减后者。

| 声明 | 数量 | 判定 |
| --- | ---: | --- |
| H1，BM25 / Dense / Hybrid 分别判定 | 3 | 题内中档均值分别减400和2000两端。两端差值均须大于0，交并 p 值取两项单侧 p 值的最大值。另报告 C 为中档均值减端点均值。 |
| H2(a)，High 组 BM25 − Dense，界值0.05 | 2 | 非劣效检验 D > −0.05，劣效检验 D < −0.05。两个方向各占一项。 |
| H2(b)，Low 组 Dense / Hybrid 各减 BM25 | 2 | 各做大于0的单侧检验。多跳作为题型探索性分析。 |
| H2(c)，全体可回答题 | 1 | Hybrid 同题分别减 BM25、Dense。两差值均须大于 −δ。交并 p 值取两个分量 p 值的最大值。 |

H2(a) 若非劣效方向的 Holm p ≤0.05，则支持该界值下非劣效。若劣效方向的 Holm p ≤0.05，则判为有劣于该界值的证据。两个方向均未通过时记为证据不足。原0.05为主要界值。0.10为次要界值，两个方向在独立的次要族做 Holm，其判定仅支持较宽界值下的次要声明。区间报告为逐对比区间，决策以校正 p 值为准。

H2(c) 的候选 δ=0.10 表示相对两种单法分别最多容许绝对 Recall 降低10个百分点。在约86道可答锁定题的预计规模下，用这个界值讨论集成收益是否足以抵偿实际可接受的召回损失。该容忍度仍需从应用价值与 Dev 功效模拟论证并在锁定前批准，不能按已看到的结果倒推。题型并列展示两差值和区间，供描述。

## 配对、证据簇和模拟精度

- 用共享金证据单元构造题目图，任何一段 gold 的单元相同即连边，取传递闭包的连通分量。一题属于一个簇，各题型和 High/Low 子组按同一全体分簇取交集。每次有放回抽取与原数目相同的簇，保留簇内所有题，以抽中题的总差值除以抽中题数，保持逐题等权的目标。报告有效簇数与最大簇。少于2簇时不估校正决定，簇很少或一个簇支配样本时明确区间不稳定。
- 主检验用原假设边界中心化的簇 Bootstrap。题级配对 percentile 区间并列作敏感性对照。小样本 n≤20 补充精确 sign-flip，按原假设界值平移逐题差值，枚举符号，含并列。它依赖在边界下差值可独立对称翻转，有共享簇或不对称时仅作诊断。主判断沿用簇检验和预定 Holm 族。
- Bootstrap 设定10000次、seed 0。采用 (极端次数+1)/(B+1)，p 最小可报告值为1/10001，落在底部表示该次模拟没有观察到更极端抽样。显示约数或明确标为模拟下限。对接近决定阈值的结果，在开启确认性评测前约定更大的固定 B 或统一增加全族的抽样次数。精确 sign-flip 与模拟 Bootstrap 的离散精度分别记录。
