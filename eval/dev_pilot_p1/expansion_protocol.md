# 扩样与假设修订草案

日期 2026-11-20。适用于 P1 后的决策。README 中的预注册原文继续作为历史依据。以下修订待项目所有者批准，所有 P1 分析仍属探索性。

## 盲生成与审核

1. 冻结法规语料、题型说明、目标配额和抽样种子。按法规、章节或主题为编题者分发原文。提前划分可用证据单元池，确保正证据按 unit ID 隔离。由独立协调者检查与旧题重合。编题者无权访问现有题面、已检视题清单、逐题分数、排名和 Pilot 错例。
2. 据原文编写问题、答案和最小证据，登记来源、起草者、证据范围和适用条件。多跳每段须提供必要信息。弃答题在两部限定文本内查相关概念和替代条文，记录确切缺失的事实。记录数字门槛、例外与替代证据。
3. 至少由一位未见检索结果的人工审核者审核每道拟纳入确认性分析的题。随机抽取约20%双审，报告答案、证据和题型的分歧与裁决。审核和修订登记日期、原字段与理由。AI 起草与人工审核分开登记，缺少确认记录时保持 pending human review。
4. 仅按语义、证据、重复、泄漏和预定配额决定接受与退回。固定随机种子在各层内分配来源单元或共享证据簇。协调者可用冻结前计算的词汇指标检查各层覆盖，保留自然分布和候选的筛选记录。同时冻结题库、标注、分析脚本、模型版本与配置。确认性评分在冻结后按批准的单次流程启动。

## 约200题的分层

保留80道既有题作为历史队列。计划新增120道，GDPR 与 AI Act 各60。每部法规新增30道 Dev 与30道锁定评估题。每个法规 × split 单元的目标如下。

| 单跳 | 多跳 | 条件或冲突 | 数值或表格 | 不可回答 | 合计 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 8 | 8 | 5 | 5 | 4 | 30 |

合并目标为单跳54、多跳51、条件33、数值33、不可回答29。总体 Dev 与锁定评估各100，法规各100。新增弃答题每个法规 × split 单元至多1道数量缺失题，全集因此最多9/29道。每部法规需列出主题覆盖与章节配额，优先选独立证据单元并记录合规的序言证据。实际分层以通过盲审的题数为准，偏差在冻结前解释。

确认性分析优先报告新增且盲审的锁定评估队列。依据隔离、审核及未见检索输出的可追溯记录，在冻结前决定是否合并既有锁定题并分层报告。规模约200是资源目标。冻结前仅用 Dev 配对差异方差做样本量模拟，按 H2(a) 的0.05及 H2(c) 的候选界值估计精度或功效。按法规和题型检验时有效样本更少。若样本不足，应报告不确定性或增加独立盲审样本。

## H2(a) amendment 草案

- 用冻结版 lexical_overlap 实现和未四舍五入分数分组。High 为 ≥0.30，Low 为 <0.30。0.20、0.25、0.40 为敏感性阈值。
- 主配置建议固定 8000 字符预算和四种固定切块尺寸等权，先在每题内汇总，再跨题配对。保留原0.05界值。令 D = BM25 − Dense，检验 H0: mean(D) ≤ −0.05，对 H1: mean(D) > −0.05。按预先约定的单侧配对置信下界或相应检验决策。若同时作多配置确认性声明，在冻结时约定共同校正族。
- 0.30 来自原题目规则，用作 H2 分组是 Pilot 后的决定。分组、汇总配置、适用队列与效应方向写入带日期的 amendment，经批准与冻结后适用于新队列。

## H2(c) 非劣效草案

- δ=0.10 为候选，代表最多容许10个绝对 Recall 百分点下降。用领域需求和预期影响论证界值，在看确认性结果前批准。Pilot 结果不能反向选择界值。
- 每个预定题型在同一题、配置和预算上分别计算 Hybrid − BM25 与 Hybrid − Dense。每个方向检验 H0: mean(D) ≤ −δ。两条单侧下界都严格高于 −δ 时，该题型才支持对两种单法的非劣效性。这个交并决策避免事后只比较当次得分较高的单法。
- 若分别宣称哪些题型达到非劣效，使用各题型的 max(p_BM25, p_Dense) 作为交并检验 p 值，再在预定题型族内 Holm。报告两种差值、单侧下界、有效 n 与分组来源。全题型声明须每个预定题型均通过。区间过宽时结论为证据不足。
