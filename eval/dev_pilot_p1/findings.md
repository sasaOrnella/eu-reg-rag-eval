- **H1 未得到 Pilot 支持。** 主预算 8000 下 BM25、Dense、Hybrid 的 C 为 −.013、−.056、−.061。三个95%区间均跨0。使用4000字符或排除7题后，任何方法的 C 也未转正。50%覆盖口径的 C 至多为0。
- **整体方法。** 8000字符、四档等权的 Dense − BM25 为 +.256（95%区间 [.112,.404]，Holm p=.0138），Hybrid − BM25 为 +.181（[.092,.274]，p=.0104），Dense − Hybrid 为 +.076（[−.011,.167]，p=.8159）。排除检视题后方向一致，前两项 Holm p 变为 .183 和 .138。4000字符四档等权的两项 BM25 差值，排除后仍通过校正（p=.0319、.0300）。
- **H2(a)。** 主分组0.30下，8000字符四档等权 High 组10题，BM25 − Dense 为 −.092（[−.267,.100]）。排除7题后 High 剩8题，估计 +.010（[−.115,.198]）。四个阈值、两个队列及两种覆盖口径的各配置均未通过对 −.05 界值的 Holm 校正检验。
- **H2(b)。** 主预算四档等权下，低重合组的 Dense 和 Hybrid 对 BM25 均为正。校正后对阈值及排除条件敏感，详见下表。多跳中，Hybrid 在4000字符、1200尺寸领先 BM25，差值 +.259（n=9，p=.0020），排除后 +.262（n=7，p=.0020）。8000字符四档等权的 Dense 和 Hybrid 各领先 +.106，校正后证据不足。
- **题型和 H2(c)。** 8000字符四档等权的单跳组，Dense − BM25 为 +.545（n=11，Holm p=.0120）。完整表包含各方法对与所有四种题型。未设定正式非劣效界值。小样本与较宽区间限制按题型解读。

### Span 覆盖

Dev 重算的792个固定尺寸配置行逐行复现了原表的 Recall、入选块数和实际字符数。50%覆盖规则使其中12行、5道题的 Recall 降低。全配置平均由 .445 降至 .435。H1、H2(a) 的上述判断相同。按 .05 比较原指标和50%覆盖的 Holm 结果，有16个对比跨过该阈值，部分 H2 比较对命中规则敏感。

## Hybrid 4000 字符异常

400 → 800 的下降为 −.217（配对95%区间 [−.364,−.086]）。33道题中10道下降、1道改善、22道持平。排除7题后 .577 → .391，下降 .186（[−.346,−.045]）。50%覆盖下仍为 .540 → .338。对照预算8000时，下降缩小到 .095。

| 候选及预算统计 | 400 | 800 |
| --- | ---: | ---: |
| 每题入选块数 | 10.03 | 5.00 |
| 每题入选字符数 | 3926 | 3741 |
| 两路各50的未截断 RRF 并集 Recall | .813 | .909 |
| RRF 前50的未装预算 Recall | .783 | .798 |
| 装预算后 Recall | .556 | .338 |

因此主要损失出现在 RRF 高位与预算前缀的组合。800档候选覆盖更高，但平均只装5块。RRF 常数60以名次融合，两个列表均出现的块可能排在仅由一路强命中的块前。存在单路遗漏、RRF 前50截断和 4000 字符截断三类机制。改变每路候选深度为10、25、50、100，800档 Recall 分别为 .399、.414、.338、.338，400档为 .540、.510、.556、.571。这是对机制的事后扰动，后续调参需单独决策。

复现中未发现排序或预算实现偏离当前规则。候选深度扰动显示融合对候选集有依赖，现有对照无法唯一归因于候选重合、分块边界或预算中的某一个因素。三个案例用于展示已观察到的机制。25道 AI 起草的可回答 Dev 题仍待人工审核，正式扩样方案和非劣效界值仍待批准。
