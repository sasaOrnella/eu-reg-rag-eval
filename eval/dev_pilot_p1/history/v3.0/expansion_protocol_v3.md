# 扩样与确认性评测协议

版本 **v3 · 2026-11-27**。在 Claude 独立复核 Dev80 复现包后，项目所有者固定总题量与分配。本次属于评分前的 Pilot 后前瞻性修订。原始预注册假设见项目 README，2026-11-26 版本保留为版本记录。[旧协议](expansion_protocol.md)

## 盲生成与审核

1. 冻结法规语料、题型说明、配额、抽样种子和证据单元池。编题者只收到指定法规原文与标注规则。协调者负责旧题去重和正证据单元的跨 split 隔离。编题与审核均隔离既有题面、检索分数、排名及错例。
2. 据原文写题、答案和最小证据，记录来源单元、约束、例外及可接受的替代证据。多跳每段须提供必要信息。弃答题查两部限定文本内的相关概念，登记所缺的事实。AI 起草元数据按题记录提供方、模型版本或可得的快照 ID、完整提示词或有版本及哈希的提示词引用、生成随机种子、生成日期（含时区）和生成参数。接口没有种子时如实登记未提供。
3. 使用盲审判断语义、证据、重复、泄漏和符合预设配额的情况。计划由独立人工审阅者审查确认性题目，随机抽约20%双审，记录分歧及裁决。起草来源与审核状态分别登记，缺少签认时保持 pending human review。
4. 协调者在评分前按冻结版 lexical_overlap 从题面和金引文计算未舍入分数，完成分层与抽样。候选及落选理由留档。冻结题库与语料哈希、主评估配置、模型版本和脚本版本。当前 Test 继续锁定。获准启动确认性评测后按一次冻结流程运行。

## 确认性配置与检验族

预算固定 **8000 字符**。Chunk Size 固定为400、800、1200、2000字符。H2 四档按题等权平均，H1 用同一题的四档构造形状对比。Hybrid 固定 **pool=50、rrf_k=60**，融合结果取前50再按严格预算入选。Dense 和 Hybrid 使用本地冻结的 Embedding 模型快照及已登记的 manifest SHA-256，版本与哈希随运行输出。主指标为任意字符重叠的 Evidence Recall。同分时，BM25、Dense 和 RRF 均按内容键排序。内容键依次使用块文本 SHA-256、来源单元全文 SHA-256 和字符坐标，不含法规名、路径或输入位置。原同分规则保留为敏感性对照。50%跨度覆盖、4000预算、单尺寸方法对比、替代重合阈值和题型对比列为探索性。

主要族共 **8 个声明**，对其 p 值一起做 Holm，族错误率 0.05。配对效应均为前者减后者。

| 声明 | 数量 | 判定 |
| --- | ---: | --- |
| H1，BM25 / Dense / Hybrid 分别判定 | 3 | 题内中档均值分别减400和2000两端。两端差值均须大于0，交并 p 值取两项单侧 p 值的最大值。另报告 C 为中档均值减端点均值。 |
| H2(a)，High 组 BM25 − Dense，界值0.05 | 2 | 非劣效检验 D > −0.05，劣效检验 D < −0.05。两个方向各占一项。 |
| H2(b)，Low 组 Dense / Hybrid 各减 BM25 | 2 | 各做大于0的单侧检验。多跳作为题型探索性分析。 |
| H2(c)，全体可回答题 | 1 | Hybrid 同题分别减 BM25、Dense。两差值均须大于 −0.10（δ=0.10）。交并 p 值取两个分量 p 值的最大值。 |

H2(a) 若非劣效方向的 Holm p ≤0.05，则支持该界值下非劣效。若劣效方向的 Holm p ≤0.05，则判为有劣于该界值的证据。两个方向均未通过时记为证据不足。原0.05为主要界值。0.10为次要界值，两个方向在独立的次要族做 Holm，其判定仅支持较宽界值下的次要声明。区间报告为逐对比区间，决策以校正 p 值为准。

### 估计量与预先指定的描述性分析

主估计对象是保留与新增 Locked Test 中所有可回答题的按题等权平均效果，High／Low 检验在对应子组内取均值。方法间差异先在同一题内计算对应差值，在 H2 中对四档等权汇总。H1 使用两个预定端点差值并补报 C。不可回答题保留为覆盖与数据组成的一部分，Evidence Recall 的估计量以可回答题为分母。

- **旧／新 Dev 差异**。用旧33道与新增36道可答 Dev 的冻结结果，报告 H1 的端点差值和 C，以及 H2 的配对差值。每个队列报告效果、n、证据簇数和95%区间，再报告「新减旧」区间。H2(a) 保持 High 子组，H2(b) 保持 Low 子组，H2(c) 用全体可答题。
- **两部法规差异**。对 GDPR 与 AI Act 分别报告同一套效应、n、证据簇数和95%区间，再报告「AI Act 减 GDPR」。在 Dev80 以及未来合法解锁并完成的 Locked Test 中分别报告。Locked Test 另按原40／新增180来源描述内部差异。
- 组间差异按同一证据簇规则重抽，对照原有题与新增题只支持描述性解释。报告名义95%区间和可回答组的计数。有限样本下的法规、写题批次、词汇重合与题型构成可能混杂。上述比较不纳入8项 Holm 主族。

### Pilot 后决策

- **H2(b) 偏离登记（2026-11-26）**。原 H2(b) 同时预测低重合和多跳题的优势。本修订明确将多跳从主要检验降为探索性分析，沿用 P1 已实现的8项主族。多跳比较及不确定性照常报告，原因是题型子组样本较小且与低重合组重叠。原假设原文保留。
- **H2(a) 功效与连续分析**。主要界值0.05要求足够精度，High 组规模及共享证据导致的有效簇数可能不足。预先报告可检出的最小差异并用 Dev 配对差值做规划。预先声明一项探索性连续分析，使用全部可回答题，按8000字符四档等权计算逐题 BM25 − Dense，对未舍入的词汇重合度做带截距线性回归。报告每增加0.10重合度的斜率与共享证据簇 Bootstrap 95%区间。该分析不改变 High 组界值或 Holm 主族，不能以斜率替代非劣效判定。
- **H2(c) 应用界值**。确认性评测的非劣效界值正式固定为 δ=0.10。这是 Pilot 后的前瞻性决策，表示在固定上下文预算下，Hybrid 相比每种单法至多容许 Evidence Recall 低10个百分点。实际用途是法规文献的人工查找辅助。融合能同时覆盖精确术语和改写查询，但可能漏掉关键依据。平均损失0.10相当于宏平均每十份必要证据单位损失约一份的量级，多跳或关键义务一段缺失就可能改变判断。因此将0.10作为最宽容的可接受损失上限，适用范围限于可人工核查的检索辅助，并并列报告50%覆盖与分题型描述以暴露平均值掩盖的风险。原始预注册未规定这一界值。

### 本轮样本量规划依据

2026-11-27 决定登记 H2(b) 的**最小有意义 Recall 收益为 +0.10**。该值用于规划和效应解释。主检验仍以0为原假设边界，另报告点估计与区间相对 +0.10 的位置。样本量规划沿用 Dev80 的单侧80% SD 上限及保守取值规则（观测 SD、证据簇 Bootstrap SD 上限、独立正态卡方 SD 上限三者取最大值）。H2(b) 的 Low 组中 Dense−BM25 的簇上限为0.4974、规划 SD 为0.5176，Hybrid−BM25 分别为0.3181与0.3291。设规划设计效应 **1.10**，独立与更强聚类作为敏感性情景。Dev80 的重复簇太少，无法可靠估计 ICC。这里登记的是 Pilot 后、确认性评分前的决策。

保守小效应情景反映规划风险。实际功效仍取决于真实效应、方差、High／Low 样本量、证据簇和 Holm 的实际检验次序。300题方案固定后据此报告效应与精度。样本量不足的分组以预定检验及区间报告其不确定性。

## 配对、证据簇和模拟精度

- 用共享金证据单元构造题目图，任何一段 gold 的单元相同即连边，取传递闭包的连通分量。一题属于一个簇，各题型和 High/Low 子组按同一全体分簇取交集。每次有放回抽取与原数目相同的簇，保留簇内所有题，以抽中题的总差值除以抽中题数，保持逐题等权的目标。报告有效簇数与最大簇。少于2簇时不估校正决定，簇很少或一个簇支配样本时明确区间不稳定。
- 主检验用原假设边界中心化的簇 Bootstrap。题级配对 percentile 区间并列作敏感性对照。小样本 n≤20 补充精确 sign-flip，按原假设界值平移逐题差值，枚举符号，含并列。它依赖在边界下差值可独立对称翻转，有共享簇或不对称时仅作诊断。主判断沿用簇检验和预定 Holm 族。
- 主协议 Bootstrap 固定 B=200000、seed 0。采用 (极端次数+1)/(B+1)，p 最小可报告值为1/200001，落在底部表示该次模拟没有观察到更极端抽样。显示约数或明确标为模拟下限。探索性扩展表可沿用10000次，分别标识抽样次数和模拟下限。精确 sign-flip 与模拟 Bootstrap 的离散精度分别记录。

## Future Research Extensions

**待 Claude 审查的草案 · 2026-11-20。** 两项均为候选方向。实验启动取决于独立方案审查和后续批准。

### 跨法规泛化（DSA、Data Act、NIS2）

- **研究价值**。在 DSA、Data Act 和 NIS2 上评估从 GDPR 与 AI Act 研究中选定的检索配置，检验方法排名、切块效果和证据召回在新法规上是否稳定。可分别设计单部法规迁移和混合语料检索，后者用于观察相近术语造成的跨法规误检。
- **数据要求**。每部法规使用同一语言的官方文本，记录版本、来源、下载日期和语料哈希。制定统一的条文、序言和附件范围。独立盲编与审核问题，标注适用法规及最小证据，保留替代证据。按法规及题型分层，并在看目标法规的结果前锁定配置。混合语料中的跨法规问题另行标记所需的每段证据。
- **风险**。法规长度、条文结构、题型比例和术语重合度可能与迁移效果混杂。相同条文的不同版本、交叉引用或近重复题可能造成泄漏。预训练模型也可能见过这些公开文本。按法规与题型报告结果与不确定性，并在设计阶段区分对新题、新索引和真正未见文本的泛化声明。

### Embedding Fine-tuning

- **研究价值**。检验法规领域微调能否改善低词汇重合及语义近似条款的区分，并观察其对 Dense 检索和使用该模型的 Hybrid 检索的影响。对照使用同一基础模型及相同的语料、切块、候选深度和预算。
- **数据要求**。需要独立的查询与相关条文或证据片段配对，以及经过核查的难负样本。按共享证据单元和近重复内容隔离训练、验证和锁定评估，目标法规外部评估集单独冻结。对训练数据记录出处、版本、使用权限和标注来源，并记录基础模型、训练参数、种子及检查点。
- **风险**。误把可接受的替代证据当负样本会损害检索。小规模数据可能导致过拟合、记住法规措辞或使其他法规的表现下降。反复按 Dev 结果选择检查点会抬高估计。需事先约定选模标准与锁定集隔离措施，并记录重建索引和推理的成本。
